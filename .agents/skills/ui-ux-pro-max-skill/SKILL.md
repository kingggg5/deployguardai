# UI/UX Pro Max Skill & Design System

This skill equips AI agents with professional UI/UX design intelligence, color palette systems, typography pairings, layout patterns, and modern aesthetic guidelines (including Magic UI design elements).

## Design System Core Principles

1. **Rich & Dynamic Aesthetics**
   - Use curated, harmonious color palettes (Obsidian canvas, paper surfaces, vibrant semantic accents like signal vermilion, cobalt blue, emerald green, and golden amber).
   - Incorporate modern glassmorphic overlays (`backdrop-filter: blur(12px) saturate(180%)`), subtle gradient borders, and ambient background glow spots.

2. **Magic UI Design Guidelines**
   - **Glow Borders & Highlights**: Subtle 1px translucent borders (`rgba(255, 255, 255, 0.12)` in dark mode, `rgba(0, 0, 0, 0.08)` in light mode) with ambient glow on active/focus states.
   - **Interactive Topography & Bento Grids**: Clean visual hierarchy using card panels with uniform 10–14px radius, clear header rails, and explicit data boundaries.
   - **Micro-Animations & Motion Physics**: Fast 160–220ms ease-out transitions for interactive state changes, pulsing status rings for active events, and smooth timeline playback.

3. **Typography Standards**
   - Primary Sans: `Inter`, `Plus Jakarta Sans`, `Segoe UI Variable`, or system sans-serif.
   - Code & Metrics Mono: `JetBrains Mono`, `Cascadia Code`, `Consolas`, monospace.
   - Distinct hierarchy: Large numbers in mono with labeled units; compact all-caps for physical instrument tags (`letter-spacing: 0.06em`).

4. **Accessibility & Usability**
   - Minimum 4.5:1 text contrast ratio and 3:1 contrast for interactive controls.
   - Distinct 2px high-visibility focus outline.
   - Support for `prefers-reduced-motion` across animations and playback scrubbers.
   - All state indicators pair color with shapes, badges, or icon labels.
